# 白底增强算法 · 设计说明

> 适用文件：`_dev/index.html` 中的 `enhanceCanvas(cv, level)`（打包后同步进 `PDF编辑器.html`）
> 最后更新：2026-09-11

## 1. 目标

让手机翻拍 / 扫描件的输出观感对标"专业扫描 App"的效果，即同时满足：

1. 纸面干净纯白，且**消除侧光、暗角造成的明暗不匀**；
2. 文字**更深更黑**，对比度提高，便于阅读识别；
3. 红色印章等真实彩色内容**保留并更鲜艳**，不被去色。

## 2. 历史问题（第一版 gamma S 曲线的缺陷）

第一版实现为：线性拉伸 + 乘性白 boost + **全局去色**（`satReduce = 0.6`）。

实测缺陷：

| 指标 | 理想效果 | 第一版输出 |
|---|---|---|
| 纯白占比 | 75.4% | 88.1% |
| 深色（<100）占比 | 5.19% | **0.15%** |
| 深色区平均亮度 | 51.9 | **81.8**（偏浅） |
| 印章 R−G 色差 | 47.0 | **14.0**（几乎无色） |

**根因**：`satReduce` 对**所有像素统一去色**，等于把最该保留的
"深色文字"与"红色印章"一起抹掉了；同时曲线方向为 gamma < 1（提亮），
把文字一并推白 → 文字、印章同时变浅。

## 3. 关键测量（推导依据）

以同一页面、两种分辨率的两张图为样本做对照测量：

- **理想效果做了光照归一化**：同一个源灰度值在页面上/中/下带输出不同
  （源灰度 130–139：上带 → 135.5，下带 → 182.5），说明并非全局曲线。
- **源图纸面亮度极差达 28**（顶部 191 → 底部 163），理想效果将其统一压到 255（极差 0）。
- **色度处理是"门限式"的**（按源绝对色度分档的色度保留率）：

| 源色度 | 含义 | 理想保留率 |
|---|---|---|
| 0–14 | 纸面泛黄 / JPEG 噪点 | 0.19–0.35（**抑制**）|
| 20–24 | 过渡 | ≈1.0 |
| 25–44 | 印章等真实彩色 | **1.29–1.45（增强）** |

结论：理想效果 = **局部光照归一化** + **压暗型色调曲线** + **色度门限降噪/增强**。

## 4. 当前实现（四趟处理）

```
Pass 0  全图纸面亮度估计   → 90 分位，作为背景下限依据
Pass 1  分块纸面估计       → BLOCK 块内亮度 90 分位（排除文字/线条）
Pass 2  块级 3×3 最大值膨胀 → 防止大块深色内容被误判为"极暗纸面"
Pass 3  双线性上采样背景图 + 逐像素映射
```

逐像素映射：

```
ratio   = 像素亮度 / 局部纸面亮度        # ratio≈1 即纸面，与位置无关 → 消除光照不均
newGray = clamp((ratio - BR)/(WR - BR), 0, 1) ^ GAMMA × 255
色度    = 低色度(<C_LO) 归零；高色度(>C_HI) 保留并按 C_BOOST 增强
出彩    = newGray + (原通道 - 原亮度) × 色度缩放
纸面    = ratio ≥ WR  →  直接纯白
```

亮度统一采用整数系数 `(R×54 + G×183 + B×19) >> 8`。

### 参数表

| 参数 | 轻度 | 标准 | 作用 |
|---|---|---|---|
| `GAMMA` | 1.00 | 1.30 | 曲线指数，越大对比越强（压暗） |
| `WR` 白点 | 0.97 | 0.93 | ratio 高于此值 → 纯白 |
| `BR` 黑点 | 0.30 | 0.30 | ratio 低于此值 → 全黑 |
| `C_LO` 色度门限下沿 | 3.0 | 3.0 | 低于此视为无彩噪点 |
| `C_HI` 色度门限上沿 | 14.0 | 14.0 | 高于此完整保留彩色 |
| `C_BOOST` 彩色增强 | 1.30 | 1.70 | 真实彩色（印章）色阶增强 |
| `C_CAP` 色度上限 | 120 | 120 | 防溢出 |
| `FLOOR_K` 背景下限系数 | 0.72 | 0.72 | × 全图纸面亮度，防深色块被洗白 |

块尺寸 `BLOCK = max(16, round(min(W,H)/17))`；分块取样为 90 分位、隔行隔列抽样。

## 5. 效果（示例图，1080×1526）

| 图像 | 均值 | 纯白% | 深色% | 深色亮度 | 印章 R−G |
|---|---|---|---|---|---|
| 原图 | 171.8 | 0.00 | 3.32 | 78.4 | 37.3 |
| 理想效果 | 234.8 | 75.40 | 5.19 | 51.9 | 47.0 |
| 旧算法 | 247.5 | 88.11 | 0.15 | 81.8 | 35.3 |
| **新·标准** | **234.5** | **75.25** | **5.30** | **51.6** | **44.6** |

真机（浏览器实际管线 1654×2337）标准档：均值 234.9 / 纯白 75.55% / 印章 R−G 47.7。

## 6. 已知取舍

- **不做锐化**：仅调色阶与色度，不引入锐化伪影；文字清晰度依赖原图分辨率。
- `FLOOR_K` 使"整页都是深色内容"的场景不会被洗白，但极端情况下
  （如整页纯黑扫描）会按原样保留深色，不做额外提亮。
- 色度门限会轻微削弱极淡的彩色（如浅色荧光笔），属预期行为。
