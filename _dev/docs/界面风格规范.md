# 「PDF编辑器」界面风格规范

> 来源：逐行分析参考项目 `workspace/图片转pdf 本地小工具/index.html`（2026-09-03 版），本规范作为后续 build-ui 步骤的复刻依据。

## 1. 配色体系（CSS 变量，直接照搬）

```css
:root{
  --bg:#f2f4f8;    /* 页面底色：浅灰蓝 */
  --card:#ffffff;  /* 卡片/头部/底栏：纯白 */
  --line:#e3e7ee;  /* 分隔线/边框：浅灰 */
  --ink:#1f2733;   /* 主文字：深蓝黑 */
  --sub:#6b7686;   /* 次要文字：中灰 */
  --acc:#2f6fed;   /* 主色/主按钮：蓝 */
  --acc-d:#1f57c8; /* 主色 hover：深蓝 */
  --ok:#1f9d55;    /* 生成/成功按钮：绿 */
  --warn:#d97706;  /* 预估/提示文字：橙 */
  --err:#dc2626;   /* 错误/删除：红 */
}
```

## 2. 字体与基础

- 字体栈：`"Microsoft YaHei","PingFang SC",system-ui,sans-serif`
- `*{box-sizing:border-box}`；`body{margin:0;background:var(--bg);color:var(--ink)}`
- 强调色文字用 `font-weight:600`（如预估体积 warn 色）

## 3. 布局骨架

```
header（白底，18px 26px padding，border-bottom:1px solid var(--line)，flex baseline gap12px）
  ├ h1 20px（emoji + 标题）  如 "📄 照片合并 PDF"
  └ span.sub 13px var(--sub) 如 "纯本地运行 · 图片不上传 · 支持 iPhone HEIC"
.wrap（max-width:1080px; margin:0 auto; padding:18px 20px 60px）
  ├ .toolbar 设置卡片
  ├ #dropzone 导入区
  └ .list 网格列表
.foot 固定底部操作条（fixed; bottom:0; 白底; border-top; padding:10px 22px; z-index:30）
```

## 4. 组件样式规范

### 4.1 工具栏设置卡片 `.toolbar`

- 下拉 select：`border:1px solid var(--line); border-radius:7px; padding:6px 8px; font-size:13.5px; background:#fff`
- 行内说明 `.est`：`13px; color:var(--warn); font-weight:600`

### 4.2 导入区 `#dropzone`

- `.drag` 态：`border-color:var(--acc); background:#eef4ff`

### 4.3 卡片网格 `.list` / `.card`
- `.list`：`margin-top:16px; display:grid; grid-template-columns:repeat(auto-fill,minmax(158px,1fr)); gap:14px`
- `.card`：白卡 `border:1px solid var(--line); border-radius:10px; overflow:hidden; box-shadow:0 1px 3px rgba(20,30,50,.05); display:flex; flex-direction:column`

## 5. 通用交互习惯（复刻）

- 主操作按钮绿（生成类）/蓝（选择类）；破坏性操作 hover 变红
- 耗时任务显示进度遮罩（进度条 + 当前处理文件名文本）
- 缩略图 canvas 绘制：白底填充 → contain 缩放（四周留白 ×0.94）→ 居中；旋转在画布上实时呈现
- 文件命名带时间戳：如 `合同PDF_20260909-1420.pdf`（本工具沿用：`PDF编辑器_日期-时间.pdf` 或基于源文件名）
- 顶栏副标题强调卖点：纯本地 · 文件不上传（本工具：纯本地运行 · 文件不上传 · 支持合并/旋转/镜像/压缩）

## 附：技术实现决策记录（编辑模块）

- **操作清单延迟写入**：旋转/镜像/删除/排序只改 state.pages 元数据（rot/hMirror/vMirror/顺序），导出时才真正写 PDF。
- **缩略图即时重绘**：thumbCache[uid] = {url, w, h} 存原始方向缩略图；每次编辑后用 makeThumbFromOps() 对原始位图做 canvas 几何变换生成 displayThumb（无需重新解析 PDF，快）。
- **撤销/重做**：history/future 栈存页面流 JSON 快照（元数据+顺序），restoreSnapshot 恢复并清理孤儿缓存/选中集。栈深限 100。
- **拖拽排序**：HTML5 DnD（dragstart/dragover/drop/dragend），依据 clientX 与目标卡中线判定插前/插后；拖拽后按新顺序重排分组分隔头。
- **徽标语义**：卡片徽标显示全局导出序号（合并语义），meta 显示源内页号 #N 与操作标记（⟳90° ⇋ ↕），尺寸显示旋转后实际展示尺寸。
- **多选删除**：选中集整批删除，若某文件全部页被删则移除该文件分组。
- **键盘快捷键**：Delete 删除、Ctrl+Z 撤销、Ctrl+Y / Ctrl+Shift+Z 重做（输入框内不触发）。

## 附：技术实现决策记录（导出管线）

- **不压缩（矢量保真）**：pdf-lib copyPages 逐源文件缓存加载 → 页面按顺序拷入新文档；旋转用 /Rotate（setRotation(degrees())），页面宽高不交换但阅读器自动旋转显示，与缩略图预览一致。
- **镜像的矢量实现限制**：pdf-lib 的 wrapContentStreams(str) 有 bug（字符串序列化失败 sizeInBytes）；手动 context.stream() 插入 Contents 数组虽文件结构正确（reload 可见 3 流），但 **pdf.js 渲染时忽略插入的直接对象流**（仅执行原内容流），无法可靠实现矢量镜像。
- **镜像最终方案**：镜像页走「pdf.js 高 DPI 渲染（scale 3.2≈230DPI）→ canvas 旋转变换 → JPEG q0.92 嵌入新页」，其余页保持矢量。视觉正确、代价是该页转为图片（文字不可选）。已在界面说明标注。
- **压缩导出梯度**：none 之外，low/medium/high 对应 quality 0.85/0.7/0.5 × scale 1.6/1.2/0.8（基准 scale 2.08≈150DPI），页面渲染为 JPEG 重编码后嵌入等尺寸新页，旋转/镜像在画布上先变换再编码。
- **ArrayBuffer 陷阱**：pdf.js getDocument({data}) 会 detach 传入 buffer → 导入时保存 ytes.slice(0) 副本供导出，每次用 .bytes.slice(0) 再传 pdf.js。
- **文件名**：单源文件保留原名 + 档位后缀 + _yyyyMMdd-HHmm.pdf；多文件用 PDF编辑器_档位_时间戳.pdf。
- **导出下载**：Blob + URL.createObjectURL + 临时 a.click()。
- **测试环境坑**：headful 浏览器窗口后台时 canvas 渲染被节流 → pdf.js render promise 挂起（is=hidden）；canvas 渲染类测试须用 headless 实例（--headless=new --remote-debugging-port）。
- **UI 自动化坑**：直接改 state.selected 不会启用编辑按钮（按钮 disabled），须真实 dispatchEvent 点击卡片触发 refreshEditbar。
