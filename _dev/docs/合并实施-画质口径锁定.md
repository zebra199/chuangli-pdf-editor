## 二、最终画质档位表（4 档，单轨）

| 档位 id | 界面文案 | 渲染 DPI | JPEG q | PDF 页行为 | 图片页行为 |
|---|---|---|---|---|---|
| `q-faithful` | **矢量保真 · 原样**（默认） | —（保真） | 0.95 | 未镜像页：`copyPages` + `/Rotate`，文字可选中 | 原分辨率、不放大，q0.95 |
| `q-high` | 高清 · 300 DPI | 300 | 0.90 | 栅格化 → JPEG | 栅格化 → JPEG |
| `q-std` | 标准 · 200 DPI | 200 | 0.82 | 栅格化 → JPEG | 栅格化 → JPEG |
| `q-lite` | 精简 · 150 DPI | 150 | 0.72 | 栅格化 → JPEG | 栅格化 → JPEG |

- **被去掉的档位**：极限压缩（100 DPI / q0.55）。若后续想更小体积，只需在 `QUALITY` 表加一行即可，无需改管线。
- **统一换算**：`渲染 scale = DPI / 72`（现开发版 `baseScale = 2.08` 即 `150/72`，PDF 侧本就是按 DPI 在算）。

```js
const QUALITY = {
  'q-faithful': { dpi: null, q: 0.95, vector: true,  label: '矢量保真 · 原样' },
  'q-high':     { dpi: 300,  q: 0.90, vector: false, label: '高清 · 300 DPI' },
  'q-std':      { dpi: 200,  q: 0.82, vector: false, label: '标准 · 200 DPI' },
  'q-lite':     { dpi: 150,  q: 0.72, vector: false, label: '精简 · 150 DPI' }
};
const DEFAULT_QUALITY = 'q-faithful';
```

## 三、等效 DPI 显示规则

- 档位下拉直接显示等效 DPI：`矢量保真 · 原样` / `高清 · 300 DPI` / `标准 · 200 DPI` / `精简 · 150 DPI`。
- **矢量保真档**：说明文字为「PDF 文字可保留选中；图片按原分辨率（不放大）」；档位后不写 DPI。
- **图片页有效 DPI 可能低于档位 DPI**（原图固有 DPI 更低时不放大）：预估区与底部信息追加一行 **「图片页有效 DPI = min(档位 DPI, 原图 DPI)」** 的实际说明，例如「2 张图片按原图 168 DPI 输出」。
- **矢量保真档下的例外页面**（镜像页兜底 300 DPI、开了白底增强的 PDF 页）在说明文字中标注「N 页以 300 DPI 栅格化」。

## 四、设置区布局（三块，职责互斥）

```
┌─ 卡片1「输出画质」（唯一画质旋钮）
│    矢量保真 · 原样（默认）/ 高清 · 300 DPI / 标准 · 200 DPI / 精简 · 150 DPI
│    + 动态说明（随档位变化；含矢量/栅格提示与等效 DPI 说明）
│    + 体积预估（一套统一公式，覆盖两类页面）
├─ 卡片2「图片排版」  标注：仅影响图片页（无图片页时置灰）
│    纸张 A4/A5 · 方向（横图自动横版 / 全部竖版）· 适配（完整显示 / 铺满裁切）
├─ 卡片3「图像增强」  标注：图片页 + PDF 栅格页均可用
│    白底增强：不增强（默认）/ 轻度 / 标准
└─ 编辑工具条不变：⟳ 旋转 · ⇋ 水平镜像 · ↕ 垂直镜像 · 🗑 删除 · ↺ 撤销 · ↻ 重做
```

**为什么这样切**：画质 = 分辨率+编码（一个旋钮）；排版 = 页面尺寸与摆放（只对图片页有意义）；增强 = 图像后处理（对任何栅格化产物都成立）。三者概念不重叠，用户心智清晰。

## 五、白底增强等能力扩展到 PDF（补充要求的落地方案）

### 5.1 适用面

| 能力 | 图片页 | PDF 页 | 说明 |
|---|---|---|---|
| 旋转 / 水平镜像 / 垂直镜像 | ✅ | ✅（现状已有） | 两类页面通用，已有实现 |
| **白底增强（自动色阶）** | ✅ | ✅ **新扩展** | 只要该 PDF 页走栅格管线，就在编码前套用 |
| 纸张 / 方向 / 适配 | ✅ | ❌ | 属排版语义，PDF 页保留源页尺寸 |

### 5.2 增强与「保真」的冲突处理（关键规则）

- 白底增强默认 **不增强**（`none`），纯 opt-in，不改默认行为。
- **矢量保真档 + 未镜像 PDF 页**：若用户开启白底增强 → 该页**强制栅格化**（300 DPI + q0.95，与镜像页兜底一致），因为矢量流无法做色阶映射。
  - UI 在开启增强时提示：「矢量保真档下，开启白底增强的 PDF 页将以 300 DPI 栅格化（文字不可选中）」。
- 增强对两类页面使用**同一个** `enhanceCanvas(cv, level)`（轻度 clip=1.0，标准 clip=2.5），代码零分叉。

### 5.3 增强对导出体积的影响

- 增强后高频细节增加，JPEG 体积上升，统一预估里对「启用增强的页」乘 `×1.05` 系数（沿用参考项目经验值）。

## 六、统一导出管线（锁定版伪码）

```js
const { dpi, q, vector } = QUALITY[qualitySel];
const enhanceOn = enhanceSel !== 'none';

for (const page of state.pages) {
  const [pageW, pageH] = pageSizePt(page);   // PDF: 源页 pt；图片: 排版算出的 pt

  // ① 唯一矢量路径：未镜像 PDF 页 + 保真档 + 未开增强
  if (page.kind === 'pdf' && vector && !page.hMirror && !page.vMirror && !enhanceOn) {
    const [tp] = await outDoc.copyPages(srcDoc, [page.srcNo - 1]);
    tp.setRotation(degrees(page.rot));
    outDoc.addPage(tp);
    continue;                                  // 不栅格化
  }

  // ② 其余全部走同一条栅格干道
  const needRaster = page.kind === 'image'
    || page.hMirror || page.vMirror || enhanceOn || !vector;
  const effDpi = (page.kind === 'pdf' && vector && needRaster)
    ? 300                                      // 保真档下的例外页兜底 300 DPI
    : dpi;
  const scale = effDpi / 72;

  let canvas = page.kind === 'pdf'
    ? renderPdfPageToRaster(srcPage, scale)                      // pdf.js
    : renderImagePageToRaster(page, pageW, pageH, effDpi, fit);  // 缩放+白底

  canvas = applyRotMirror(canvas, page.rot, page.hMirror, page.vMirror); // 同一套变换
  if (enhanceOn) enhanceCanvas(canvas, enhanceSel);                      // 同一套增强
  const jpeg = encodeJpeg(canvas, q);                                    // 同一套编码
  const img = await outDoc.embedJpg(jpeg);
  outDoc.addPage([pageW, pageH]).drawImage(img, { x: 0, y: 0, width: pageW, height: pageH });
}
```

结构：**一个矢量特例 + 一条统一栅格干道**，图片/PDF 共用渲染、变换、增强、编码、落页代码。

## 七、统一体积预估（锁定公式）

```
bytesPerPixel(q)：0.95→0.35  0.90→0.28  0.82→0.20  0.72→0.14   (与 4 档一一对应)

est = Σ(栅格页)  targetPx × bytesPerPixel(q) × (增强 ? 1.05 : 1)
    + Σ(矢量页)  源文件大小 × (该页占源文件页数比)
    + 固定开销 8KB
显示：「已导入 N 个文件 · M 页 · 预计约 X MB（误差 ±30%）」
```

- 矢量页 = 保真档下未镜像且未开增强的 PDF 页（按源文件均摊字节）。
- 图片页无「不放大」导致的体积虚增：预估使用有效 DPI 对应的 `targetPx`。

## 八、边界与风险（锁定处理方式）

| 项 | 处理 |
|---|---|
| 纯 PDF 文档选栅格档 | 文字失去可选中；说明文字明确提示，推荐「矢量保真」 |
| 纯图片场景选「矢量保真」 | 无矢量可言 → 退化为原分辨率最高质量，不报错、不困惑 |
| 保真档 + 白底增强 | PDF 页强制 300 DPI 栅格化，UI 提前提示 |
| 镜像页 | 必须栅格（pdf-lib 无可靠矢量镜像，已验证）；保真档下 300 DPI 兜底 |
| 图片开「铺满裁切」 | 允许放大，按适配意图优先，不额外警告 |
| 大页 PDF + 300 DPI | 逐页让出主线程 + 进度条；后续可加「超限自动降档」 |
