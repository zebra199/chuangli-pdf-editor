> 我方推荐：5 档 + 默认「矢量保真」+ 显示等效 DPI + 排版独立成卡。

### 3.2 实施步骤（建议顺序）

1. **数据模型**：`pages[]` 加 `kind:'pdf'|'image'`；`files[]` 加图片字段（bitmap/natW/natH/heic/proxyBytes）；新增 `imgSettings`（纸张/方向/适配/增强）
2. **导入分流**：`addFiles()` 单入口按扩展名分流；新增 `addImageFile()`（HEIC→heic2any 转 JPEG、EXIF 用 `createImageBitmap({imageOrientation:'from-image'})` 纠正、异步解码）
3. **缩略图渲染分支**：`makeThumbFromOps()` 按 kind 取源图（PDF 用 thumbCache 位图 / 图片用 bitmap）
4. **画质单轨改造**：把现有 `compressSel`（4 档）替换为「输出画质」5 档（DPI+q 绑定）；导出管线重构为「一个矢量特例 + 一条统一栅格干道」
5. **移植图片导出模块**：`planFor`（纸张/方向/适配算页尺寸与摆放）、`renderCanvas`（白底→旋转→缩放→增强）、`enhanceCanvas`（自动色阶白底增强）
6. **设置面板分区**：「输出画质」+「图片排版（仅图片页）」两张卡
7. **体积预估统一**：一套公式覆盖两类页面（targetPx × bytesPerPixel(q) + 矢量页均摊 + 8KB）
8. **内嵌 heic2any**：库 1.3MB，单文件版将增至约 3.7MB
9. **全功能验证**：纯图片 / 纯 PDF / 混合 / HEIC / 各画质档 / 撤销重做 / 排序

### 3.3 统一画质方案要点（核心设计）

- **统一量**：`渲染 scale = DPI / 72`（现有代码 `baseScale 2.08` 就是 `150/72`，PDF 侧本就是按 DPI 算的）
- **统一公式**：`页面栅格像素 = ceil(页宽pt × DPI/72) × ceil(页高pt × DPI/72)`
- **5 档**（DPI 与 JPEG 质量绑定）：矢量保真(—/q0.95) / 高清(300/q0.90) / 标准(200/q0.82) / 精简(150/q0.72) / 极限(100/q0.55)
- **唯一特例**：未镜像的 PDF 页 + 矢量保真档 → `copyPages` + `/Rotate`，保留矢量文字可选
- **镜像页必须栅格**（pdf-lib 无可靠矢量镜像），矢量保真档下用 300 DPI 兜底
- **图片永不放大**：有效 DPI = min(档位 DPI, 原图固有 DPI)
- **独立出去**：纸张/方向/适配（排版）与白底增强（图像后处理）不算画质，单独成卡并标注「仅影响图片页」

### 4.2 已踩过的坑（血泪，别重犯）

| 坑 | 现象 | 解决 |
|---|---|---|
| `canvas.getContext('2d', {alpha:false})` | Edge 下 pdf.js `render()` promise **永久挂起** | 用默认 `getContext('2d')` |
| pdf.js `getDocument({data})` | **detach** 传入的 ArrayBuffer，之后复用报错 | 保存 `bytes.slice(0)` 副本；每次传 `f.bytes.slice(0)` |
| pdf-lib `wrapContentStreams(str)` | 序列化崩溃 `sizeInBytes is not a function` | 不可用 |
| 手动插内容流做矢量镜像 | 文件结构正确（reload 可见 3 流）但 pdf.js 渲染**忽略**插入的流 | 放弃，镜像页改**栅格化**处理 |
| headful 浏览器后台标签 | canvas 渲染被节流，render promise 挂起（`document.visibilityState==='hidden'`） | canvas 类测试用 `--headless=new --remote-debugging-port` |
| UI 自动化点按钮无效 | 直接改 `state.selected` 不会启用编辑按钮（按钮 disabled） | 必须 `dispatchEvent(new MouseEvent('click',{bubbles:true}))` 点卡片 |
| 单文件构建 replace 损坏 | pdf-lib 代码含大量 `$`，被当替换模式 | 用**函数式 replace**（`() => '<script>'+code+'</script>'`） |
| HTTP 服务编码 | `Invoke-WebRequest` 的 `.Content` 按 Latin-1 解码，中文误判缺失 | 用 `WebClient.DownloadData` + UTF8 解码，或直接读字节 |
