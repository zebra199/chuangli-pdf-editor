# PDF-
创立PDF编辑器是一个完全在本地运行的单文件 PDF 工具。它不需要安装、不需要联网，下载 创立PDF编辑器.html 双击打开即可工作——你导入的所有文件都只在本机浏览器里处理，不会上传到任何服务器。  功能上，它把 PDF 与图片放进同一个页面流：可直接拖动缩略图跨文件合并与排序，支持旋转、水平/垂直镜像、删除页面，并覆盖完整的撤销重做。整册效果支持文字或图片水印、自动重编号的页码（居中/左下/右下）；页面内可做马赛克打码、荧光高亮、自由画笔、透明底文本框，图片页还能自由拖动摆放与缩放。导出提供矢量保真、高清 300、标准 200、精简 150 四档画质，可选白底增强，并实时预估输出体积（与真实导出偏差约 1%~3%）。  采用 MIT 协议开源，免费使用与二次分发。
