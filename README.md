# 创立PDF编辑器

**一个 HTML 文件，就是一个完整的 PDF 编辑器。** 双击打开即用，不安装、不联网、不上传。

> 🔒 所有处理都在你的浏览器里完成 —— 代码中**不含任何网络请求**，文件不会离开本机。

---

## ✨ 能做什么

**组织页面**

- 导入 **PDF / JPG / JPEG / PNG / HEIC**（iPhone 照片可直接用），PDF 与图片**混合排在同一个页面流**里
- 拖拽缩略图调整顺序，跨文件合并为一个 PDF
- 旋转 90°、水平/垂直镜像、删除页面（PDF 页与图片页通用）
- 撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z），覆盖旋转、删除、排序、设置与标注

**整册效果**

- **水印**（文字或图片）：字号、颜色、透明度、角度、间距可调，作用于全部页
- **页码**：居中下 / 左下 / 右下，格式与起始编号可调，**不随旋转变化**、跟随页面排序自动重编号
- 开启后**缩略图与预览图即时可见**，所见即所得

**在页面上标注**

- **画笔**：自由涂画，可选颜色与粗细
- **马赛克**：拖出矩形即把该区域打成像素块，用于遮盖敏感信息
- **区域高亮**：荧光笔效果，底下文字仍可读
- **文本框**：直接输入中文，支持多行自动折行，**底色纯透明**
- **图片摆放**：图片页可拖动位置、缩放（10%~400%）、一键"适应页面"
- 所有标注画完可再选中：拖动移动、改颜色、删除（画笔笔迹不支持改粗细，重画一笔即可）

**导出**

- 四档画质：**矢量保真**（PDF 文字仍可选中）/ 高清 300 / 标准 200 / 精简 150
- 可选**白底增强**，把扫描件的灰底拉白（轻度 / 标准）
- 每页可单独覆盖画质与增强设置
- **体积预估**：按来源文件分组真实采样编码，实测与真实导出偏差约 1%~3%

## 🚀 怎么用

1. 下载仓库里的 **`创立PDF编辑器.html`**（约 3.8MB）
2. **双击打开**（推荐 Chrome / Edge）
3. 拖入文件 → 调整 → 点底部绿色「生成 PDF」

不需要安装任何东西，也不需要联网。拷到 U 盘、发给同事，双击就能用。

详细功能说明见 **[使用说明.md](使用说明.md)**。

## 🛠 自己构建（可选）

交付的 `创立PDF编辑器.html` 是把依赖全部内联后的产物。想改功能的话：

```bash
node _dev/build_single.cjs     # 由 _dev/index.html 重新生成 创立PDF编辑器.html
```

`_dev/index.html` 是开发版源码（体积小、可读），依赖同目录的 `_dev/lib/`；
改完跑一次构建脚本即可覆盖根目录的交付文件。

回归测试（可选，需本机有 Edge/Chrome）：

```bash
cd _dev/verify
node brush_test.cjs          # 画笔 26 项
node overlay_test.cjs        # 叠加层 25 项
node estimate_test.cjs       # 体积预估精度 8 项
node run_legacy.cjs          # 6 个旧套件（共享一个无头实例）
```

## 🔧 技术栈

pdf-lib（PDF 生成 / 页面拷贝 / 旋转）＋ pdf.js（预览渲染 / 栅格化）＋ heic2any（HEIC 转码），
纯前端，无任何后端。EXIF 拍摄方向自动纠正。支持 ES2017+ 的现代浏览器。
